# 💧 Bot de Irrigación - Asistente Virtual

Bot de WhatsApp desarrollado en Node.js para la gestión automatizada de consultas de regantes.

## 🚀 Tecnologías
- **Core:** Node.js
- **WhatsApp:** whatsapp-web.js
- **Scraping:** Puppeteer
- **Base de Datos:** SQLite

## 🛠️ Funcionalidades
- Consulta de Deuda (Sincronización Batch).
- Validación de Padrón.
- Información de Turnos y Contacto.
- Menú Interactivo.

## 📦 Instalación
1. `npm install`
2. Configurar `.env`
3. `npm start`
